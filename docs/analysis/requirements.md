# 项目需求

> 本文是功能需求、交互流程和验收口径的唯一权威来源。
> 技术实现见 [技术设计](technical-design.md)，界面规格见 [UI 设计规范](ui-design.md)。

## 1. 产品概述

**项目名称**：自动打字 (Automatic Typing)

**产品定位**：Windows 桌面通用文字输入工具。通过模拟真实键盘输入，把文字逐字送入目标窗口，适用于禁止粘贴、只能手动输入的文本框。

产品不再只面向代码输入，默认场景为文章 / 作业，同时保留代码输入能力。

## 2. 用户场景

### 2.1 文章 / 作业

- 长段落、中文标点、自然停顿
- 默认保留原文缩进
- 使用阅读友好的中文字体
- 适合作文、作业、普通文本框

### 2.2 代码

- 等宽字体
- 默认跳过行首缩进，依赖目标编辑器自动缩进
- 保留特殊符号、换行、Tab 和 Unicode 支持
- 适合 PTA、IDE、在线编辑器

## 3. 核心需求

### R1 - 文本输入

- 提供多行文本编辑器，支持粘贴和手动输入
- 支持一键读取系统剪贴板
- 支持清空文本
- 空文本时显示占位提示，不把占位文字当作实际内容
- 显示字数、行数和预计用时

### R2 - 场景预设

| 预设 | 字体 | 默认节奏 | 倒计时 | 跳过行首缩进 | 自然节奏 |
|---|---|---|---|---|---|
| 文章 / 作业 | Microsoft YaHei UI 14 | 90 ms/字 | 3 秒 | 关闭 | 开启 |
| 代码 | Cascadia Code / Consolas 13 | 150 ms/字 | 3 秒 | 开启 | 开启 |

规则：

- 默认选中“文章 / 作业”
- 切换预设应用默认字体、节奏、倒计时、缩进和自然节奏
- 切换预设不清空已输入文本
- 运行期间禁止切换预设和修改参数

### R3 - 打字参数

- **节奏**：30ms ~ 500ms / 字，默认文章 90ms、代码 150ms
- **自然节奏**：开启时在基础间隔上叠加 ±30% 随机波动
- **倒计时**：1 / 3 / 5 / 10 秒可选，默认 3 秒
- **跳过行首缩进**：默认文章关闭、代码开启
- 速度显示人类可读标签和每分钟字符数估算

### R4 - 交互状态

| 状态 | 主按钮 | 停止按钮 | 说明 |
|---|---|---|---|
| 就绪 | 开始打字 | 隐藏 | 可编辑、可调参数 |
| 倒计时 | 取消 | 隐藏 | 提示切换到目标窗口 |
| 输入中 | 暂停 | 显示 | 编辑器和参数锁定 |
| 已暂停 | 继续 | 显示 | 从暂停位置继续 |
| 完成 | 再次开始 | 隐藏 | 显示完成和用时 |

- 自然完成和用户停止必须区分，停止后不得显示“完成”
- 倒计时、输入中、暂停时编辑器只读
- 完成后恢复编辑和参数

### R5 - 字符兼容

- 英文字母、数字
- 代码常用符号：`{}[]()<>;:""''!#$%^&*+-=/\|~`
- 换行（Enter）、制表符（Tab）
- 中文、中文标点
- emoji、全角符号等 Unicode 字符
- ASCII 字符走扫描码模式，非 ASCII 字符回退 Unicode 模式

### R6 - 界面

- 主界面采用“编辑器 + 底部控制栏”
- 顶部显示应用名、副标题、置顶和主题按钮
- 场景切换位于编辑器上方
- 编辑器底部显示读取剪贴板、清空和字数统计
- 控制栏包含节奏、倒计时、主按钮、停止按钮、进度和状态
- 高级设置包含跳过行首缩进和自然节奏
- 支持浅色 / 深色主题
- 支持窗口置顶
- 使用 Lucide 开源图标，附许可证

### R7 - 平台与打包

- Windows 10 / 11
- 无需管理员权限
- Python 3.10+，开发与验证环境 3.13
- 使用 PyInstaller 打包为独立 `.exe`
- 打包后图标资源可用

## 4. 使用步骤

1. 启动程序，默认进入“文章 / 作业”场景。
2. 粘贴或输入文字，或点击“读取剪贴板”。
3. 根据需要切换“代码”场景、调整节奏和倒计时。
4. 点击“开始打字”。
5. 在倒计时结束前切换到目标窗口并保持前台。
6. 打字过程中可以暂停、继续或停止。
7. 完成后可以再次开始。

## 5. 注意事项

- 倒计时结束前必须切换目标窗口，否则文字会输入到本程序。
- 目标窗口保持前台激活。
- 目标编辑器没有自动缩进时，关闭“跳过行首缩进”。
- 目标编辑器自动补全可能产生多余闭合括号，建议关闭自动补全。
- 打字速度过快可能触发平台风控，建议 100ms–300ms。

## 6. 非功能性需求

- 界面简洁、现代、信息层级清晰
- 浅色和深色主题下文字、边框、图标对比度可读
- 长文本编辑和滚动流畅
- 不提交构建产物、缓存和生成资源
- 文档与代码同步更新
