# UI 设计规范

> 本文是配色、字体、图标、布局和控件规格的唯一权威来源。
> 功能需求见 [项目需求](requirements.md)，技术实现见 [技术设计](technical-design.md)。

## 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 窗口背景 | `#e8f4fd` | 浅蓝底色 |
| 标题栏背景 | `#4a90d9` | 强调蓝 |
| 标题文字 | `#ffffff` | 白色 |
| 副标题文字 | `#d0e4ff` | 浅蓝白 |
| 正文文字 | `#1a1a2e` | 深色 |
| 状态文字 | `gray` | 灰色 |
| 卡片/面板底 | `#f0f8ff` | 极浅蓝 |
| 边框 | `#b8d4f0` | 浅蓝灰 |
| 按钮主色 | `#4a90d9` | 与标题栏一致 |
| 按钮悬停 | `#3a7bc8` | 深一级 |
| 幽灵按钮 | `transparent` + border | 次要操作 |
| 幽灵按钮文字 | `#2c3e50` | 深灰蓝，确保在浅蓝背景上可读 |
| 幽灵按钮禁用文字 | `#95a5a6` | 浅灰蓝，禁用态区分 |
| 复选框文字 | `#1a1a2e` | 深色正文 |
| 复选框边框 | `#4a90d9` | 与强调色一致 |

## 字体

| 场景 | 字体 | 字号 | 字重 |
|------|------|------|------|
| 标题 | Microsoft YaHei | 20px | Bold |
| 副标题 | Microsoft YaHei | 12px | Normal |
| 正文/代码 | Microsoft YaHei | 13px | Normal |
| 按钮（主） | Microsoft YaHei | 14px | Bold |
| 按钮（次） | Microsoft YaHei | 13px | Normal |
| 状态栏 | Microsoft YaHei | 12px | Normal |

> Microsoft YaHei（微软雅黑）为 Windows 系统自带字体，无需额外安装，无版权问题。

## 图标

使用 Unicode 符号，无需外挂图标库：

| 图标 | 用途 |
|------|------|
| ⌨ | 标题标识 |
| 📋 | 读取剪贴板 |
| 🗑 | 清空文本 |
| ▶ | 开始 / 继续 |
| ⏸ | 暂停 |
| ⏹ | 停止 |
| ✅ | 完成状态 |

## 窗口规格

| 属性 | 值 |
|------|------|
| 默认尺寸 | 700 × 560 px |
| 最小尺寸 | 500 × 400 px |
| 启动位置 | 屏幕居中 |
| 缩放 | 可拉伸 |
| 外观模式 | Light（强制浅色） |

## 圆角与间距

| 组件 | 圆角 | 内边距 |
|------|------|--------|
| 文本框 | 8px | - |
| 按钮 | 6px / 8px | - |
| 面板 | - | 10px |

## 可访问性

- 按钮状态（enabled / disabled）视觉区分明显
- 透明按钮文字颜色 `#2c3e50` 在浅蓝背景上保持可读性
- 状态栏实时反馈当前操作阶段
- 倒计时阶段状态栏明确提示用户切换窗口
