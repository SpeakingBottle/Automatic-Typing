# UI 设计规范

> 本文是配色、字体、图标、布局和控件规格的唯一权威来源。
> 功能需求见 [项目需求](requirements.md)，技术实现见 [技术设计](technical-design.md)。

## 1. 设计方向

- 现代、清爽、轻量
- 以文字内容为主体，控件不抢视觉焦点
- 单一强调色，细边框，克制阴影
- 同时支持浅色和深色
- 使用 Lucide 线性图标，不使用 emoji 充当功能图标

## 3. 字体

| 场景 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 标题 | Microsoft YaHei UI | 16 | Bold |
| 副标题 / 说明 | Microsoft YaHei UI | 12 | Normal |
| 正文 / 标签 | Microsoft YaHei UI | 13 | Normal |
| 主按钮 | Microsoft YaHei UI | 14 | Bold |
| 字数统计 | Microsoft YaHei UI | 12 | Normal |
| 文章编辑器 | Microsoft YaHei UI | 14 | Normal |
| 代码编辑器 | Cascadia Code / Cascadia Mono / Consolas | 13 | Normal |

字体从候选列表中选择系统中第一个可用字体。英文界面沿用同一套字体候选，优先 Microsoft YaHei UI 的拉丁字形，缺失时回退 Segoe UI；切换语言后按钮和标签宽度需保持不截断。

## 4. 窗口与布局

### 窗口

| 属性 | 值 |
|---|---|
| 默认逻辑尺寸 | 760 × 700 |
| 最小逻辑尺寸 | 620 × 600 |
| 启动位置 | 屏幕居中 |
| 缩放 | 可拉伸 |
| 外观模式 | 默认浅色，可切换深色 |
| 开始打字后 | 自动最小化，完成或停止后恢复 |

实际像素尺寸由 Windows DPI 缩放决定；窗口按逻辑尺寸创建并交给 customtkinter 缩放。

### 布局

```text
┌──────────────────────────────────────────────────────────┐
│ ⌨ 自动打字      把文字逐字输入任意窗口   [语言] [置顶] [主题] │
├──────────────────────────────────────────────────────────┤
│ 场景   [ 文章 / 作业 ]   [ 代码 ]                         │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ 在这里输入或粘贴文字...                              │ │
│ │                                                      │ │
│ │                                                      │ │
│ └──────────────────────────────────────────────────────┘ │
│ [读取剪贴板] [清空]                      0 字 · 0 行      │
├──────────────────────────────────────────────────────────┤
│ 节奏   ─────────●────────  自然 · 90 ms/字 · 约 667 字/分 │
│ 倒计时 [3 秒 ▾]                    [▶ 开始打字]  [■]     │
│ █████████████░░░░░░░  正在输入 120/500 · 剩余约 45 秒     │
│ 高级设置 ▾                                               │
└──────────────────────────────────────────────────────────┘
```

### 尺寸

- 窗口外边距：16px
- 卡片间距：8–12px
- 卡片内边距：14–16px
- 标题栏高度：约 56px
- 场景栏高度：约 40px
- 编辑器最小高度：160px（会随窗口拉伸）
- 图标按钮：32 × 32
- 主按钮：高 38，圆角 10
- 停止按钮：38 × 38，圆角 10
- 卡片圆角：12
- 编辑器圆角：10

## 5. 组件

### 标题栏

- 左侧：键盘图标、标题“自动打字”、副标题“把文字逐字输入任意窗口”
- 右侧：语言按钮（`languages`）、置顶按钮、主题按钮
- 语言按钮在中文 / English 之间切换，切换后保持当前文本、预设和参数
- 图标按钮带 tooltip

### 场景栏

- 标签“场景”
- 分段按钮“文章 / 作业”“代码”
- 选中项使用 accent 背景和白色文字
- 运行期间禁用

### 编辑器卡片

- 白色/深色卡片，1px 边框，12px 圆角
- 多行文本编辑器，占满主区域
- 占位文字：`在这里输入或粘贴文字…`
- 底部工具栏：
  - 读取剪贴板图标按钮
  - 清空图标按钮
  - 右侧字数 / 行数
- 运行期间只读

### 控制卡片

- 节奏滑块：30–500ms，显示“节奏标签 · ms/字 · 约 N 字/分”
- 倒计时下拉：1 / 3 / 5 / 10 秒
- 主按钮：开始打字 / 取消 / 暂停 / 继续 / 开始打字
- 停止按钮：仅输入中或暂停时显示
- 进度条：0–100%
- 状态栏：就绪、倒计时、正在输入、已暂停、完成、错误
- 高级设置折叠按钮
- 高级设置内容：
  - 跳过行首缩进开关
  - 自然节奏开关

### 倒计时与控制浮层

- 位置：屏幕顶部水平居中，距顶部约 22px
- 无边框、20px 圆角、1px 边框、置顶
- 倒计时模式：
  - 左侧为 80px 圆环，圆环随剩余秒数递减，中心显示大号秒数
  - 右侧显示“准备开始”和“N 秒后开始 · 请切换到目标窗口”
  - 右上角提供取消图标按钮
- 控制模式（倒计时结束后）：
  - 左侧状态点和“正在输入 / 已暂停”
  - 中间显示“当前/总数 · 百分比 · 剩余约 X”
  - 右侧为暂停/继续按钮和停止按钮
  - 底部为 6px 进度条
- 倒计时结束后不销毁窗口，直接切换为控制条
- 点击继续时把焦点还给最近的目标窗口，避免输入落入浮层
- 主窗口在开始后最小化，完成或停止后恢复
- 切换语言或主题后同步更新文案和颜色

## 6. 图标

使用 Lucide 1.72.0（ISC License）。

| 图标 | 用途 |
|---|---|
| `keyboard` | 应用图标、标题 |
| `clipboard` | 读取剪贴板 |
| `trash-2` | 清空 |
| `play` | 开始 / 继续 |
| `pause` | 暂停 |
| `square` | 停止 |
| `x` | 取消倒计时 |
| `languages` | 中英文切换 |
| `pin` / `pin-off` | 窗口置顶 |
| `sun` / `moon` | 主题切换 |
| `chevron-up` / `chevron-down` | 高级设置 |

图标资源位于 `assets/icons/`，按 `light`、`dark`、`on_accent` 三种颜色目录保存，许可证见 `assets/icons/LICENSE`。

## 7. 状态与反馈

| 状态 | 主按钮 | 状态栏 |
|---|---|---|
| 就绪，空文本 | 开始打字（禁用） | 请输入要输入的文字 |
| 就绪，有文本 | 开始打字 | 就绪 · 预计用时 X |
| 倒计时 | 取消 | N 秒后开始，请切换到目标窗口 |
| 输入中 | 暂停 | 正在输入 current/total · 剩余约 X |
| 已暂停 | 继续 | 已暂停 |
| 完成 | 开始打字 | 完成 · 用时 X |
| 错误 | 开始打字 | 具体错误提示，使用 danger 颜色 |

## 8. 可访问性

- 主要文字和背景保持足够对比度
- 图标按钮提供 tooltip
- 禁用态与可用态在颜色和状态上可区分
- 禁用态主按钮使用浅色背景和主题色图标，避免白色图标与浅色背景混在一起
- 状态变化通过文字明确说明，不只依赖颜色
- 浅色和深色主题分别验证文字、边框和图标可读性
