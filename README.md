# 项目需求文档

## 项目概述

**项目名称**: 自动打字 (Automatic Typing)

**项目目标**: 开发一款 Windows 桌面软件，将用户提供的文本/代码通过模拟键盘输入的方式逐字输入到目标窗口，绕过平台的禁止粘贴限制。

## 背景与动机

某些平台作业可能设置了禁止粘贴代码的功能。用户在完成作业时需要逐字手动输入代码，效率低下。本工具通过模拟真人键盘输入来解决此问题。

## 核心需求

### R1 - 文本输入
- 提供多行文本框，用户可粘贴或手动输入待打字的文本/代码
- 支持一键读取系统剪贴板内容并填入文本框

### R2 - 打字参数配置
- **打字速度**: 可调节每个字符之间的基础间隔（30ms ~ 500ms），默认 150ms（模拟熟手打字速度）
- **随机延迟**: 在基础间隔上增加 ±30% 的随机波动，模拟真人打字节奏，避免被检测
- **倒计时**: 开始打字前有可配置的倒计时（1 ~ 10 秒），默认 3 秒
- **跳过行首缩进**: 复选框控制（默认开启），开启后引擎跳过每行开头的空格和 Tab，依赖目标编辑器自身自动缩进，避免缩进叠加

### R3 - 打字控制
- **开始**: 倒计时结束后自动逐字输入
- **暂停/继续**: 打字过程中可暂停，调整后继续
- **停止**: 随时终止打字

### R4 - 字符兼容
- 英文字母（大小写）
- 数字
- 代码常用符号: `{}[]()<>;:""''!#$%^&*+-=/\|~`
- 特殊控制字符: 换行（Enter）、制表符（Tab）
- 中文字符: 汉字、中文标点（使用 Unicode 模式发送，与 ASCII 字符自动切换）
- 其他 Unicode 字符: emoji、全角符号等

### R5 - 平台兼容
- 运行平台: Windows 10 / Windows 11
- 无需管理员权限
- 不依赖目标窗口类型（适用于任意可接收键盘输入的程序）

## 使用步骤

### 方式一：粘贴代码

1. 复制需要输入的代码/文本到系统剪贴板（Ctrl+C）
2. 双击 `启动自动打字.bat` 启动软件
3. 点击 **📋 读取剪贴板**，文本自动填入输入区
4. 根据需要调整打字速度、倒计时和**跳过行首缩进**选项
5. 点击 **▶ 开始打字**
6. 倒计时期间（默认 3 秒），将光标切换到目标输入框（如 PTA 答题框）
7. 等待自动打字完成

### 方式二：手动粘贴到文本框

1. 双击 `启动自动打字.bat` 启动软件
2. 将代码直接粘贴到软件的文本输入区（Ctrl+V）
3. 根据需要调整打字速度、倒计时和**跳过行首缩进**选项
4. 点击 **▶ 开始打字**
5. 倒计时期间，将光标切换到目标输入框
6. 等待自动打字完成

### 打字过程中

| 操作 | 按钮 | 说明 |
|------|------|------|
| 暂停 | 点击 **⏸ 暂停** | 打字暂停，按钮变为 **▶ 继续** |
| 继续 | 点击 **▶ 继续** | 从暂停位置继续打字 |
| 停止 | 点击 **⏹ 停止** | 终止打字，可重新开始 |

### 注意事项

- 倒计时结束前务必切换到目标窗口，否则文字会输入到软件自身的文本框中
- 打字速度过快可能被平台检测为异常，建议保持在 100ms ~ 300ms 之间（默认 150ms）
- 目标窗口保持前台激活状态，不要切换窗口
- **跳过行首缩进**适用于目标编辑器自带自动缩进的情况。如果目标编辑器无自动缩进（如记事本），请取消勾选以保留原文缩进
- 某些编辑器的自动补全功能可能导致多余的闭合括号，建议在目标编辑器中关闭自动补全
