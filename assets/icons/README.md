# Lucide Icons

- Source: https://lucide.dev/
- Package: `lucide-static@1.72.0`
- License: ISC License (see `LICENSE`); some Feather-derived icons are MIT
- Variants:
  - `light/`: `#475569`
  - `dark/`: `#CBD5E1`
  - `on_accent/`: `#FFFFFF`
- `assets/app.png` and `assets/app.ico` are generated by the same script.
- The ICO contains 16/20/24/32/40/48/64/128/256px frames rendered directly from SVG.

Regenerate:

```bash
cd tools
npm install
cd ..
node tools/render_icons.mjs
```
